# BAR_IMPACT Examples

This directory contains example scripts demonstrating how to use the BAR_IMPACT package.

## 📝 Available Examples

### `basic_workflow.py`
Demonstrates the core functionality:
- Loading and processing convergence maps
- Adding shape noise
- Applying BNT transforms
- Basic analysis pipeline

Run with:
```bash
python examples/basic_workflow.py
```
